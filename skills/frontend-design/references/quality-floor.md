# 可见质量下限

把本文件当作最终浏览器循环的风险索引，不当作固定打勾仪式。只检查当前表面真实存在的内容、组件和状态；每个问题都要能连接到用户理解、操作、可访问性或视觉一致性的具体损失。

## 内容与层级

- 每个元素回答用户真实问题、推进任务或建立必要结构；不能说明用途的装饰、重复标题、虚构指标和无去向 CTA 应退出。
- 空白通过构图、比例和节奏解决，不靠新增段落、评价、Logo 墙、徽章或功能区块填满。
- 首屏或主工作区应在短时间内说清对象、当前状态和主要动作。一个决策上下文只有一个明确 primary action；次要动作不能用同等重量争抢。
- 卡片只用于真实的分组、比较或交互单元。表格、时间线、地图、图表和 inspector 是真实工作模型时，保留它们的扫描关系。

## 视觉与品牌

- 优先使用品牌和现有系统的准确颜色、字体与素材；通用字体和常见组件可以使用，但必须是被上下文支持的选择，不能成为无意识默认。
- 新建配色时先确定暖、冷或中性语气，将主要有彩色控制在少量角色中，并让 neutral 与 semantic state 承担其余工作。颜色不只为了“更丰富”。
- 平色优先于装饰性渐变；渐变确实承担层级或品牌责任时，保持少量同调色 stop 和受控对比。光晕、blob、噪点和纹理也需要同样的理由。
- 形状、圆角、边框和阴影表达同一层级模型。不要把大圆角卡片、左侧彩边、pill、badge 或阴影当成所有内容的默认包装。

## 排版与节奏

- 正文在移动端通常不低于 16px；桌面正文根据产品密度保持可读。长文行宽通常控制在约 65–75ch，标题和控件需要真实字体加载后的换行检查。
- 没有既有尺度时从 4px 或 8px 节奏建立 spacing token；重复形成韵律，只有层级或构图需要时才打破。不要让所有间距相同，也不要让每处都成为一次性值。
- 字号、字重、颜色、位置和留白共同形成 primary、secondary、tertiary 层级。低对比小字不能用来伪装精致。

## 交互与反馈

- 当前流程实际使用的控件覆盖 default、hover、active、focus、disabled、loading 等状态；触屏主交互不能依赖 hover 才暴露。
- 点击、提交、筛选、切换和选择立即给出状态变化。异步按钮在运行时禁用重复提交；错误靠近字段并可被辅助技术读到；成功和当前选择不能沉默。
- 可点击区域在触屏上至少约 44×44px，相邻目标通常保留至少 8px 间隔。危险且不可逆操作需要与真实风险相称的确认或撤销路径。
- 微交互通常在 150–300ms 内完成；每个视口只保留少量承重动效。支持 `prefers-reduced-motion`，不闪烁、不制造 layout shift，也不让进入动画阻挡内容。

## 无障碍

- 普通文字对比度至少 4.5:1；大文字、UI 边界和 focus indicator 至少 3:1。状态不能只靠红绿或明暗区分。
- 优先使用 `button`、`a`、`nav`、`main`、`label`、正确 heading 等语义元素；只有原生语义不足时再增加 ARIA。
- 所有功能可由键盘到达，tab 顺序与视觉顺序一致；modal 和 drawer 管理 focus，`Escape` 能关闭，focus ring 持续可见。导航很长时提供 skip link。
- icon-only 控件有 accessible name；有意义图片有准确 alt；输入具有可见 label、合适 `type`、`inputmode` 与 `autocomplete`；错误使用 `aria-live` 或 `role="alert"` 等可感知反馈。

## 响应式与加载

- 没有既有约定时从 mobile-first 开始。至少检查约 375px 的移动宽度和目标桌面宽度；在 768px、1024px 或项目实际断点附近发生结构变化时补查相邻宽度。
- 页面没有意外横向滚动；图片随容器缩放并预留尺寸；全屏移动布局考虑 `dvh`；sticky/fixed 区域计入可用高度。
- 稠密表格可以水平滚动、冻结关键列或简化次要信息，但不能自动拆成失去列关系的卡片。编辑器、图表和 inspector 同样优先保留任务关系。
- 字体避免不可见加载，首屏素材使用合适尺寸与格式，非首屏图片按需 lazy-load。性能优化不能改变内容或交互契约。

## 最终可见检查

在真实浏览器中确认：字体、图标、图像和数据加载；标题、按钮、标签和表格没有裁切；空、错、加载、禁用和长内容状态没有破坏布局；主要键盘路径与 focus 可见；移动端没有重叠、溢出或过小目标；主要动作从入口走到反馈终态。没有接触到的状态保留为未验证，不能靠代码阅读写成已经成立。
