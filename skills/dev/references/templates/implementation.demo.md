# Implementation 产物 Demo

`implementation.md` 只在实现需要跨会话保存或交接时创建。它保存实际交付与聚焦反馈，不成为需求、设计或代码的第二份权威来源。

```markdown
# Implementation：<任务承诺>

## 实际交付

- 对象与基线：<实际修改的分支、提交或工作树状态>
- 已实现行为：<代码现在提供什么行为，以及聚焦反馈实际观察到什么>
- 根因与实现边界：<问题落在哪里，为什么改到这里>

## 变更

- `<文件或模块>`：<对行为的实质作用>

## 偏离与决定

<与当前设计、计划或评审结论的实质偏离及理由；没有则写无。>

## 聚焦反馈

- `<命令、重放或状态回读>`：<实际结果，以及它能证明什么>

## 证据边界与交接

- 尚未证明：<完整测试、环境或路径缺口>
- 剩余风险：<仍由谁承担什么>
- 下一入口：<下一位应读取或运行的对象>
```
