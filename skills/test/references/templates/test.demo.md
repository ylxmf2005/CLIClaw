# Test 产物 Demo

`test.md` 保存本轮被测对象、环境、可重放证据与裁决。开放日志、截图和原始输出仅在正文放不下且需要独立核验时进入 `evidence/`。

```markdown
# Test：<被测对象>

## 裁决

- 对象：<版本、构建、分支或提交>
- 环境：<入口、身份、数据与关键配置>
- 结论：成立 | 失败 | 证据不足
- 核心依据：<什么终态证据决定当前结论>

## 承诺与证据

### <被测承诺>

- 可重放动作：<命令、请求或用户旅程>
- 实际终态：<结果真正生效或被真实消费者观察的一端发生了什么>
- 证据：<输出、状态、日志、截图或外部接收结果>
- 分项结论：成立 | 失败 | 证据不足
- 结论边界：<该证据能证明到哪里>

## 失败、缺口与剩余风险

- 已观察失败：<保留每次真实矛盾及触发条件>
- 证据缺口：<未执行、不稳定或被阻塞的路径>
- 下一位：<需要 Shape、Dev、Owner 或其他环境完成什么>
```
