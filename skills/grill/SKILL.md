# grill

## 只把当前决定前沿交给用户

从 `context.md`、Current Artifacts 和真实对象重建方向。没有 Context 时，说明 Grill 只能处理已建立的 Task，并请用户显式调用 Shape 启动 Task；本轮 Grill 不内部转交，也不把当前调用改写成 Shape Task。把未决事项看成有依赖的决策树：前置决定尚未成立的分支先不问；当前不需要猜测就能回答的全部问题，组成这一轮的决定前沿。

事实由 Agent 从代码、运行现场、文档和工具中查明。交给用户的是价值、偏好、范围、风险接受与授权。一个问题需要背景时，先讲清关系、推荐答案和代价；默认用户没有读过当前产物，也不把补查事实转交给他。

每轮提出整个当前前沿并等待回答。用户的答案会改变后续依赖，因此每轮之后重新计算，不沿旧问卷机械前进。调查只挂起依赖该事实的分支，其他已经成熟的问题继续。

## 决定回到拥有它的地方

用户确认且需要跨轮或交接的决定，不能只留在聊天里。把它写回唯一权威来源：Goal、Scope、Non-goals 与 Acceptance Evidence 由 `shape` 修订 `context.md`；需求、设计、契约或其他专业结论回到拥有它的当前产物。提交、部署或外部写入等一次性授权只服从当前消息与宿主权限，不沉淀为可复用的任务授权。来源尚不存在时说明缺口，并请用户显式调用 Shape 建立或修订；本轮 Grill 仍不内部转交，也不自行创建 Task、权威来源、`grill.md` 或平行决定日志。

回答推翻任务方向或专业前提时，先修订受影响的权威来源，再继续展开依赖它的决定；不能让较新的聊天答案和较旧的持久产物同时有效。

## 在共同理解处停止

当承重分支已经决定或明确保持未决、没有关键假设被藏起来、持久决定已经回到权威来源，并且用户确认双方理解一致，Grill 结束。用户的困惑或“我不知道”不是同意；它必须保留为具名未知及其影响。

方向需要重开时，请用户显式调用 `shape`；方向成立且用户授权继续时交给 `dev`。Grill 不开始实现，不替 `review` 独立证伪，也不替 `test` 提供完成证据。
